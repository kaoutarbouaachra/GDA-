# GDA- — GKNN + CAM experimental repository (assembled snapshot)

This package combines GKNN source code supplied in the conversation with
our consolidated CAM implementation, experimental tracking, SLURM arrays,
and the extended Figure 8 analysis.

**This is NOT a verified clone of the GitHub repository.** Network access to
GitHub was unavailable. Some pre-existing repository files (notably datasets,
fold files, original `README.md`, utilities, and experiment scripts) could not
be recovered. The base model was reconstructed from the user's uploaded
GKNN code and contains our selected log-det option; a CAM factory was inserted.
The file `run_training.py` here is a compatibility launcher for `run_tracked.py`,
not a byte-for-byte copy of the user's local script.

See `README_START_HERE.md` and `PACKAGING_NOTES.md` before running. For the exact
local repository, upload a ZIP exported from VS Code, then this package can be
merged with full fidelity.
