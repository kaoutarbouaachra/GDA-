# Data not included in this assembled ZIP

This archive contains the GKNN source files supplied in the conversation and
CAM/experiment scripts created here. It **does not contain the dataset binaries**
(`data/ori_dataset/*`, `data/processed/*`) or saved fold files from the user's
local repository because those bytes were not available in the container.

Copy `data/ori_dataset/`, `data/folds/` and any required raw/processed files from
your local `GDA-` directory into this tree before running real datasets.
Do not infer equivalence to the exact `main` branch of GitHub.
